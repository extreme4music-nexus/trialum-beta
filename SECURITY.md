# Security policy / Безбедност

Do not reveal vulnerabilities, service addresses, private user data,
passwords, certificates, API tokens, or signing keys in public Issues,
pull requests or CI logs.

Use GitHub's private vulnerability reporting feature if enabled.
If unavailable, open an issue requesting a private contact channel
WITHOUT posting vulnerability details.

The public repository receives only owner-approved, pre-screened beta
snapshots. There is no automatic upstream sync.

NEVER publish Android release keystores, signing passwords, Play Console
credentials, FCM service-account files, real backup data or production
server secrets. Official APK/AAB signing is local only.
