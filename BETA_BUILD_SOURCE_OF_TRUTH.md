## Version handoff rule

When the owner starts a new app version, create its branch from the previous version's final approved build branch, preserving that branch's complete state. Record the new branch here only after confirming the source branch and version. Keep previous version branches intact as historical build sources.

The beta repository is the source of truth for beta code. Android build artifacts are generated by GitHub Actions; official release signing is performed locally by the owner. Never commit signing keys or passwords.
