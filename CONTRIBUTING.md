# Contributing to Trialum / Придонеси

Trialum's official development is **owner-controlled**. This public repo
is a distribution channel for approved beta-source snapshots, not a
collaborative development mirror.

## Welcome / Добредојдени
- Submit reproducible bug reports through Issues.
- Suggest improvements, accessibility changes or new ideas.
- Do not post personal data, confidential material or secrets.

## Code submissions
Please do **not** submit code, images, audio, model files or other protected
materials without first obtaining the project owner's explicit agreement.

A submission is not automatically accepted, merged, credited as a contracted
contribution or entitled to a financial share. Before any accepted contribution
is incorporated, the parties must agree in writing on:
- authorship and third-party licensing;
- appropriate reuse / commercial publication rights for the owner;
- any recognition or compensation;
- handling of warranties and intellectual-property claims.

Only the project owner can authorize merges, releases, official product
branding, or collaborator write access. GitHub proposals do not change this.

For vulnerabilities, use SECURITY.md rather than public Issues.
