# Trialum 1.1 — translation-only update

The Play release uses versionName `1.1` and the next required Android versionCode `40`. It contains localization changes only; the separate v40 feature work is not included.

Play Console release notes (translated):

## English (en)

Bug fixes and translations only. Translations have been updated across all supported languages, including the full User Agreement, and untranslated interface text has been fixed.
