## Scope and behavior

- **All pets always own lifelong local memory.** Their development unlocks the ability to talk via a separately chosen supported local LLM. Changing models or disabling AI does not delete memory.
- Private chat in 1.4 v44 is English-only; a direct built-in translator is explicitly deferred to a later release. No hidden cloud translation is introduced.
- Voice input uses Android 12/API 31+ `createOnDeviceSpeechRecognizer`, requests `RECORD_AUDIO` only on tap and does not fall back to cloud recognition. Voice output chooses an installed English TTS voice marked **non-network**. Trialum does not retain audio recordings. Actual device support depends on installed Android/Google speech packages and permissions.
- English room dialogue is a distinct opt-in online feature: the WSS service may handle **public** English pet speech for authorized room participants. No private owner chat is included in the room context or intentionally sent to the server.
- No new Google Play purchase or merchandise integration is in this change.

## Regression and release gates

`tests/v44-chat-privacy-release.test.cjs` checks the actual Android Mini status contract, unified model selection, unchanged memory on model switch, English-only private input, outgoing private-entity disclosures, V44 terms and Privacy Policy links, offline voice API contract and displayed version. `tests/playground-ai.test.cjs` asserts canonical English public speech and the conditional Macedonian display. Existing V44 cognitive, encrypted archive, stress, Android Kotlin compilation and migration tests remain enabled in `.github/workflows/v44-unified-cognitive-memory.yml`.

**Not claimed as tested yet:** physical Android on-device speech recognition, Android TTS audio output, actual downloaded Mini/Advanced model quality, signed APK installation, external server translation, traffic inspection, battery/thermal and a device-only privacy audit. These must be verified on an isolated owner-approved QA build before a release merge.

**Do not change internal saved-world schema identifiers merely to rebrand the release display.** They are migration compatibility values, not the 1.4 v44 release label.
